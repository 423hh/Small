这条链路是怎么走通的

1

POST /login

提交用户名密码，AuthenticationManager 调用 UserDetailsService 查 sys_user 表，用 BCrypt 比对密码。

2

签发 JWT

认证通过后用 HmacSHA256 生成令牌，默认有效期 120 分钟，页面把它存在浏览器里。

3

GET /helloWorld

请求头带上 Authorization: Bearer 令牌，过滤器校验签名与过期时间，通过后返回 HelloWorld。

页面由 Spring Boot 内置静态资源提供：src/main/resources/static/index.html。后端未启动时，这页的请求会失败。
